# 🧠💾 Memory And Hard Disk Test

A lightweight Windows batch utility that provides quick access to **memory (RAM) testing** and **hard disk/SSD diagnostic tools** through a simple command-line menu.

Designed for **PC users, technicians, hardware troubleshooting, and basic system diagnostics**.

## ✨ Features

### 🧠 Memory / RAM Testing

The Memory menu provides quick access to several online memory and RAM testing resources:

1. **Memory Test (RAM)**
   https://www.codeitbro.com/tool/memory-test-ram

2. **WuTools.com**
   https://wutools.com/hardware/performance/storage-read-write-test

3. **Web Online RAM Speed Test**
   https://peyty.github.io/web-online-ram-speed-test/

4. **SystemRequirements RAM Speed Checker**
   https://systemrequirements.net/tools/ram-speed-checker

5. **RAM Tester Online**
   https://techtester.online/ram-tester/

6. **Memory Speed Test**
   https://nbstool.com/en/tool/memory-speed-test

7. **FPSTESTs**
   https://fpstests.net/

### 💾 Hard Disk / SSD Testing

The Hard Disk menu provides quick access to storage diagnostic and health-monitoring tools:

1. **CrystalDiskInfo**
   https://crystalmark.info/en/software/crystaldiskinfo/

2. **Hard Disk Sentinel**
   https://www.hdsentinel.com/

3. **PassMark DiskCheckup**
   https://www.passmark.com/products/diskcheckup/

## 🚀 How to Use

### 1. Download the Project

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/memory-hard-disk-test.git
```

Or download the repository as a ZIP file from GitHub.

### 2. Run the Batch File

Open the downloaded project folder and double-click the `.bat` file.

You can also run it from Command Prompt:

```cmd
MemoryAndHardDiskTest.bat
```

### 3. Select a Test Category

The main menu provides:

```text
==================================
Memory And Hard Disk Test
==================================
1. Memory
2. Hard Disk
0. Exit
```

Choose:

* `1` — Open the Memory/RAM testing menu
* `2` — Open the Hard Disk/SSD testing menu
* `0` — Exit the application

## 🧠 Memory Menu

The Memory menu contains several resources for checking RAM performance and memory-related information.

```text
=======================================
Memory
=======================================
1. Memory Test (RAM)
2. WuTools.com
3. Web Online RAM Speed Test
4. SystemRequirements
5. RAM Tester Online
6. Memory Speed Test
7. FPSTESTs
0. Back
```

Selecting an option automatically opens the corresponding website using the Windows default web browser.

## 💾 Hard Disk / SSD Menu

The storage menu provides access to commonly used disk health and diagnostic tools.

```text
==================================
Hard Disk SSD/HDD
==================================
1. CrystalDiskInfo
2. Hard Disk Sentinel
3. PassMark DiskCheckup
0. Back
```

These tools can be used to inspect storage health, SMART information, drive status, and other disk-related information, depending on the capabilities of the selected tool.

## 🎯 Purpose

The purpose of this utility is to provide a convenient central menu for accessing memory and storage testing resources.

Instead of manually searching for different diagnostic websites and tools, users can select a category and launch the required resource directly from the batch interface.

This can be useful for:

* 🧑‍💻 PC users
* 🛠️ Computer technicians
* 🔧 Hardware troubleshooting
* 🧠 RAM performance testing
* 💾 HDD/SSD health checking
* 🖥️ Basic PC diagnostics

## 🔐 Security & Privacy

This batch file does not install additional software or modify Windows system settings.

The program primarily uses the Windows `start` command to open external websites in the user's default browser.

When using third-party websites or diagnostic services, review their privacy policies and avoid entering sensitive or unnecessary information.
